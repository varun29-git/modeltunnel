# Terminus Lean 150M: 2B-token ternary QAT continuation

**Status: completed.** This stage trained for 1,999,998,976 additional tokens and 5,087 updates from the SHA-verified 10B dense-FP8 checkpoint (`3d116e88…67f2144684b`). The final QAT checkpoint SHA-256 is `ceee823262d11e914eb63d6a396c3df90fb47e5dd9301f7db0f8add0a468c29f`. See [the combined analysis](analysis/COMBINED_DENSE_QAT_SCALING_REVIEW.md), [compact metrics](analysis/combined_metrics.json), and [the results guide](../../docs/RESULTS.md).

The 25-layer, width-640 architecture, DeepGEMM path, and FP8 activations were retained while all effective projection weights became fully ternary (`weight_mode="ternary"`, strength 1). FP32 latent weights and Muon optimizer moments carried into the new phase. All three peak base learning rates were halved from 0.01 to **0.005** after loading the moments. The fresh WSD schedule used 200M warmup, 1.4B stable, and 400M cosine decay to 10% of peak.

The packed corpus held 12.890B train tokens, including 2.890B unused after dense training. Only about 748M fresh English tokens remained, so QAT used **37% English, 13% code, 13% math, and 37% Indic** rather than the dense 50/10/10/30 mix. `prepare_views.py` derives exact per-source offsets from the dense deterministic routing schedule and reuses the original checksummed shards and validation split without retokenization. Phase/data counters restarted explicitly; optimizer moments and RNG state were retained.

The launcher verifies data, runs native ternary preflight, converts the checkpoint, trains with exact resume, and audits completion. The finalizer verifies external S3 and Blob copies before requesting deallocation. Public service templates contain placeholder storage/account/resource identifiers and are not ready-to-run launchers. Raw checkpoints, packed data, event logs, initial evaluation, and verification receipts are external.

Final QAT loss was worse than the dense parent on every tracked source: under dense validation weighting, 2.6042 versus 2.4194. **No matched dense continuation or downstream QAT suite has been run**, and the mixture, source position, and schedule changed along with weight mode. This single regression trial does not establish a causal ternary quality tax or an optimal QAT duration, mixture, or learning rate.
